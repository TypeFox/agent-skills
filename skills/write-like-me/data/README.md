# Bundled data

`ai-style-patterns.json` is the AI style-patterns DB: patterns extracted from the maintainers' corpus of AI-generated documents (repo-root `data/write-like-me/ai-generated/`; 30 documents from the GPT, Claude, and Gemini families across articles, reports, LinkedIn posts, talk abstracts, and an email thread split into eight files by conversation stage) with the technique in `../references/technique.md` (see its maintainer note), in the format of `../references/db-schema.md` with `"kind": "ai"`. Its rates are register-weighted (`corpus.register_weights`: article 4, report 2, social 2, abstract 2, email 1 — db-schema.md, Register weighting), so that neither the 13 articles nor the one email thread defines every rate by word count alone; ranges, spreads and tiers stay unweighted.

Processing measures the input against both DBs in one run — `textstats.py measure INPUT --db USER_DB.json --db data/ai-style-patterns.json` — and uses this DB's rows as the AI-evidence column of the comparison table. Its `stat` fields reference the built-in `ai_*` counters of `../scripts/textstats.py`, so the counters remain the executable definitions; the DB adds the corpus rates, spreads, tiers, and verbatim evidence behind them, plus the `register_scope` fields and model-split notes the counters cannot carry. The DB is refreshed by re-running extract mode over the corpus when a new model generation visibly shifts the distribution or corpus documents are regenerated; the current DB is the second extraction (2026-09-09).
