# Skill Evals

Measure whether a skill actually improves an agent's output: run prompts with and without it, grade both against the same assertions, and iterate.

Source: [skills/skill-evals](https://github.com/TypeFox/agent-skills/tree/main/skills/skill-evals)

## Install

```sh
npx skills add TypeFox/agent-skills -s skill-evals
```
